# 使用与排错

在 Zotero 的“编辑 → 设置 → 高级 → 设置编辑器”中搜索 `extensions.zotero.ZoteroAnkiBridge`。

| 设置名末尾 | 用途 |
| --- | --- |
| deckName | 牌组名称 |
| modelName | 笔记类型名称 |
| frontField | 保存单词的字段名称，必须是笔记类型第一个字段 |
| backField | 保存译文的字段名称 |
| tags | 标签，以逗号或空格分隔 |
| endpoint | 本机 AnkiConnect 地址，默认为 http://127.0.0.1:8765 |
| apiKey | 仅在 AnkiConnect 配置了认证时填写，不能填翻译服务密钥 |

修改后重新划词。新安装默认使用 README 列出的中文名称；如果你的 Anki 使用 Basic / Front / Back，需要改为对应名称。插件只检查已有牌组和字段，不自动创建。

## 保存的内容

正面为选择文本，背面为匹配当前文本、文献和服务的翻译结果。复用现成结果的条件不满足时，会通过 Translate for Zotero API 请求当前配置服务；这可能产生翻译用量。词典结果和其他文献的旧结果不会冒充当前配置的翻译结果。

同一牌组与同一笔记类型中，已有词不会再次新增或覆盖。不同牌组可以分别保存同一个词。标签、笔记类型和字段名称以实际 Anki 配置为准。

## 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 插件安装被拒绝 | 使用 0.1.1 或更新版本；核对 Zotero 为 10.0.x；不要使用旧 0.1.0 XPI |
| 划词后没有按钮 | 确认桥接插件启用；重新划词或重启 Zotero；若问题只出现在独立阅读窗口，请在 Issue 中注明 |
| 提示翻译插件不可用 | 启用 Translate for Zotero，并选择配置好的翻译服务 |
| 无法连接 AnkiConnect | 保持 Anki 打开，检查 AnkiConnect 是否启用及本机端口是否正确 |
| 提示牌组或字段不存在 | 名称须完全一致；单词字段必须是笔记类型的第一个字段 |
| 翻译超时或空结果 | 先检查翻译服务，恢复后点击重试 |
| 提示已存在 | 不新增，也不会改动旧译文 |

按钮显示“已加入”表示 AnkiConnect 返回了笔记编号，第一次必须在 Anki“浏览”中核对内容。网络在提交时中断的情况下，先检查是否已经保存，再重试。

## 安装后的检查

维护者已确认当前版本实际可用。新用户首次安装后，可按下面的步骤确认自己的牌组和字段配置。

1. 选择一个尚未加入牌组的单词，等待译文后点击添加。
2. 在 Anki 核对词、译文、牌组和笔记类型。
3. 重新选择同一单词并点击，应显示已存在。
4. 关闭 Anki 后尝试另一个词，应显示错误；重启 Anki 后应能重试。
5. 如使用独立阅读窗口，单独检查按钮显示与关闭窗口后的行为。

## 卸载

在 Zotero 插件列表中停用或移除桥接插件。已加入 Anki 的笔记保留。Translate for Zotero 和 AnkiConnect 的安装与设置由各自插件管理。
